# Social Media Drafts

Ready-to-post copy for sharing this project across platforms.
All numbers are pre-filled from the empirical results in `paper/results/`.

**Update before posting**: replace `[arxiv_link]` and `[medium_link]` with actual URLs once published.

## Files

- `hackernews.md` — title + first comment for Hacker News
- `reddit_algotrading.md` — r/algotrading post
- `twitter_thread.md` — 8-tweet thread
- `linkedin.md` — professional/recruiter-facing post
- `habr.md` — Habr / VC.ru post (Russian)

## Suggested posting cadence

1. **Day 1**: arXiv preprint + GitHub repo public
2. **Day 2**: LinkedIn (professional network reach first)
3. **Day 3**: Medium / Substack (English version)
4. **Day 4**: Hacker News (timing: Tuesday 9 AM Pacific is empirically best)
5. **Day 5**: Twitter/X thread
6. **Day 7**: r/algotrading + r/quant (timing: Sunday evening EST)
7. **Day 10**: Habr / VC.ru (Russian audience)

Spacing prevents spamming the same people across platforms and lets each conversation breathe.

## Disclosure

Always disclose authorship clearly. Never use clickbait titles like "I MADE $XXXk WITH THIS!" — the whole point of this work is the opposite of survivorship-biased success reporting.
